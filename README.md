# FreelanceTimer

FreelanceTimer is a native macOS app for tracking freelance work and staying focused.

## Features

- Focus timer with configurable focus and break lengths
- Timed and untimed breaks
- Task tracking with reusable recent tasks
- Color-coded tags for organizing work
- Billable and non-billable sessions with hourly-rate estimates
- Daily focus goals and progress tracking
- Session history, project summaries, and weekly activity reports
- Menu bar controls for the active timer
- English and Turkish interface

## Requirements

- macOS 15 (Sequoia) or later
- Xcode 16 or later

## Run from source

Install Xcode, then open Terminal and run:

```bash
git clone https://github.com/mahmutcancansoy/freelance-timer.git
cd freelance-timer
swift run
```

You can also open the project in Xcode:

```bash
open Package.swift
```

Select **My Mac** as the run destination and press **⌘R**.

## Install a downloaded release

When a macOS release is available, download the `.dmg` file from the repository's [Releases](https://github.com/mahmutcancansoy/freelance-timer/releases) page, open it, and drag FreelanceTimer into the **Applications** folder.
